# FlowDesk SaaS Dashboard

A modern SaaS admin dashboard built with React, TypeScript, Vite, Tailwind CSS, React Query, Zustand, React Hook Form, and Zod.

## Features

- Protected authentication flow
- Dark / light theme system
- Responsive dashboard layout
- Analytics overview cards
- Revenue chart
- Users management
- Billing / subscriptions management
- Search, filters, sorting, pagination
- URL query param synchronization
- Loading skeletons
- Empty and error states
- Edit and delete confirmation modals
- React Query queries and mutations
- Toast notifications
- Form validation with Zod
- Reusable UI components

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack React Query
- Zustand
- React Hook Form
- Zod
- Recharts
- Sonner
- Lucide React

## Learning Focus

This project focuses on scalable frontend architecture, reusable components, async state management, form validation, UI state handling, and real SaaS dashboard patterns.
